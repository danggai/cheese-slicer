# 치즈 슬라이서

치지직 VOD 부분 다운로드 사이트인 치즈 슬라이스를 더 편하게 사용하기 위한 크롬 확장프로그램입니다.

## 설치 방법

1. [Releases](../../releases)에서 최신 `.zip` 다운로드
2. ZIP 압축 해제
3. Chrome 주소창에 `chrome://extensions` 입력
4. **개발자 모드** 활성화
5. **압축해제된 확장 프로그램을 로드** 클릭
6. 압축 해제한 폴더 선택

> ZIP 파일이 아닌 **압축 해제된 폴더**를 선택해야 합니다.

## 업데이트

새 버전의 ZIP을 다운로드한 뒤 기존 확장프로그램을 삭제하고 최신 폴더를 다시 로드하면 됩니다.
